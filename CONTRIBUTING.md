# Contributing

Booth Engineer is open source, but closed to outside contributions, in the style of SQLite. We don't accept pull
requests. Bug reports are welcome as issues once the project is public; please include your music server, its
version and what you expected to happen.

You're free to fork it under the GNU General Public License, version 3 or later. The protocol schemas and API
docs in `protocol/` are Apache-2.0, so other clients and servers can implement them under any license.
